# Portfolio Project Instructions

## Project

This is a personal portfolio website for Mona Sabeti, a software engineering
graduate applying for software development, cybersecurity, data and technology
roles.

## Technology

- Next.js App Router
- TypeScript
- Tailwind CSS
- ESLint
- npm

## Requirements

- Keep the design professional, modern and easy to scan.
- Make all pages fully responsive.
- Prefer reusable React components.
- Keep portfolio content in files under `src/data`.
- Use Next.js `Image` for project images where appropriate.
- Use Next.js `Link` for internal navigation.
- Avoid adding large dependencies without a clear reason.
- Do not add a backend unless it is genuinely required.
- Ensure `npm run lint` and `npm run build` pass after changes.

## Planned Sections

1. Navigation
2. Hero
3. About
4. Experience
5. Featured projects
6. Skills
7. Education
8. Footer

## Visual Direction

- Clean and polished
- Strong typography
- Neutral colour palette with one accent colour
- Generous spacing
- Subtle animations only
- Avoid excessive gradients, glass effects and decorative clutter
